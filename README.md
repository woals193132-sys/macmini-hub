# AI 본부 관제 허브

사장님과 맥미니 본부장이 함께 쓰는 모바일 관제 화면입니다.

2026-11-18에 **1실 6그룹** 조직도를 만들고, 같은 날 저녁 **v4 — "오늘의 실전 관제 보드"** 로 첫 화면을 갈아엎었습니다. 조직도는 현황을 보는 화면이라 매일 들어갈 이유가 약했기 때문에, **매일 아침 열면 바로 쓸모 있는 것**(시황·결재·1분 학습·주거/청약)을 1번 탭으로 올리고 조직도는 2번 탭으로 내렸습니다.

2026-11-19 **v5 — 재테크 실전 엔진** 으로 재테크그룹을 알림 조직에서 실제로 돈을 불리고 지키는 조직으로 올렸습니다. 대기 현금 파킹, 분할 익절선, 연간 고정 부수입 루프, 청약 판정 카드(예상 가점·실투입금), 월별 성과 감사 보드가 들어갔고, 뉴미디어스튜디오의 채널을 **「호러트래커」(미스터리·호러·미제사건)** 로 바꿨습니다.

2026-11-19 낮 **v6 — 법무·고문 라인** 을 붙였습니다. 감사·법무 라인에 **법무·컴플라이언스팀**(호러트래커·재테크·라이프 검수)을 신설하고, 조직마다 1:1 전담 **고문단 6인**을 두어 *고문 진단 → 실행팀 반영 → 결과 측정 → 고문 재검토* 를 주 1회 돌립니다.

- `index.html` — 화면 (5탭: **오늘** · 조직도 · 작업 · **재테크** · 시스템)
- `data.json` — 화면에 들어가는 상태 데이터 (오늘 보드 · 조직도 · 알림 · KPI · 보드 · 응모 · 자동화 현황)
- `hub.html` — 데이터를 안에 넣은 단독 실행용 파일 (`index.html` + `data.json`)
- `build.py` — `data.json`을 `index.html`에 넣어 `hub.html`을 다시 만듭니다 (`python3 build.py`)
- `render_check.py` — 브라우저 없이 렌더링을 점검합니다 (`python3 render_check.py hub.html --brief`). 퀴즈 정답 공개·영어 뜻 보기·조직 상세 시트까지 실제 클릭으로 확인합니다.
- `leak_check.py` — 공개로 나가는 파일에 직장명·거주지·실명·소득·시드 같은 개인 정보가 섮였는지 검사합니다 (`python3 leak_check.py`).
- `deploy.sh` — 저장소로 밀어 넣고 GitHub Pages 상태를 확인합니다 (`sh deploy.sh`)
- `manifest.webmanifest`, `icon-*.png` — 홈 화면에 앱처럼 추가하기 위한 파일

색인을 막아 두었습니다(`noindex`). 전화번호·이메일·상세 주소·카드/주문 정보·직장(회사·사업장) 이름·거주 구 이름은 넣지 않습니다.
데이터를 바꾸려면 `data.json`만 고치고 `python3 build.py`를 다시 실행하면 됩니다.

## 1번 탭 — 오늘 브리핑 (v4)

상단 히어로에 날짜와 오늘의 한 줄, 그리고 **결재 대기 / 1분 학습 / 신규 매물 / 내일 마감** 4개 숫자를 둡니다. 그 아래 4개 모듈:

1. **📈 오늘 장전 시황 & 레버리지**
   - **기화가거 투자 인사이트**(11/18 07:51): 엔비디아 3Q 매출 1,158억 달러 · 450억 가이던스, 시간외 +2.5%, 코스피200 야간선물 +0.10%, '순환 금융' 우려(공급 구매 약정 +40% · 클라우드 임대 +38%) 체크, 원문 링크
   - **인사이트레이더**(스레드): "시장은 걱정마셔라" — 르네상스 엔비디아 축소 · 마이크론/AMD 확대 흐름
   - **KODEX 레버리지 3분할 게이지**: 현재가와 1·2·3차 목표선(50,000 / 45,000 / 40,000원)을 눈금으로 표시하고, 1차선까지 남은 금액·%를 계산해 보여 줍니다. 축 양 끝은 **오늘 고가 ↔ 52주 최저**입니다.
2. **✅ 사장님 결재 대기** — 지금 결정이 필요한 것만 남깁니다. 각 항목에 마감(D-day)·무엇을 정하면 되는지·안 정하면 생기는 일을 함께 적고, 채팅에 "2번 승인" 한마디로 처리할 수 있게 했습니다.
3. **📚 오늘의 1분 학습**
   - **산업안전기사 4지선다**: 실제 기출 형식 문제 6문제를 날짜로 돌려가며 보여 주고, 답을 누르면 정답·해설이 열립니다. "다른 문제"로 다음 문제.
   - **영어 프리토킹 1표현**: 발음·뜻·예문 + **한글 뜻 보기** 토글, **🔊 발음 듣기**(Web Speech API, 아이폰 Safari 지원) 버튼. 표현 6개를 날짜로 순환합니다.
4. **🏠 오늘 주거·청약 · 라이프** — 사당역 원룸 신규 건수, 청약 마감(D-day), 이번 주 데이트 코스 3안 요약(코스·이동시간·경비), 내일 알림.

학습 카드는 `data.json`의 `today.study` 배열만 늘리면 문제·표현이 계속 늘어납니다. 날짜 기준으로 자동 순환하므로 매일 따로 고칠 필요가 없습니다.
