2026-11-19 낮 **v6 — 법무·고문 라인** 을 붙였습니다. 감사·법무 라인에 **법무·컴플라이언스팀**(호러트래커·재테크·라이프 검수)을 신설하고, 조직마다 1:1 전담 **고문단 6인**을 두어 *고문 진단 → 실행팀 반영 → 결과 측정 → 고문 재검토* 를 주 1회 돌립니다.

- `index.html` — 화면 (5탭: **오늘** · 조직도 · 작업 · **재테크** · 시스템)
- `data.json` — 화면에 들어가는 상태 데이터 (오늘 보드 · 조직도 · 알림 · KPI · 보드 · 응모 · 자동화 현황)
- `hub.html` — 데이터를 안에 넣은 단독 실행용 파일 (`index.html` + `data.json`)
- `build.py` — `data.json`을 `index.html`에 넣어 `hub.html`을 다시 만듭니다 (`python3 build.py`)
- `render_check.py` — 브라우저 없이 렌더링을 점검합니다 (`python3 render_check.py hub.html --brief`). 퀴즈 정답 공개·영어 뜻 보기·조직 상세 시트까지 실제 클릭으로 확인합니다.
- `leak_check.py` — 공개로 나가는 파일에 직장명·거주지·실명·소득·시드 같은 개인 정보가 섮였는지 검사합니다 (`python3 leak_check.py`).
- `deploy.sh` — 저장소로 밀어 넣고 GitHub Pages 상태를 확인합니다 (`sh deploy.sh`)
- `manifest.webmanifest`, `icon-*.png` — 홈 화면에 앱처럼 추가하기 위한 파일

색인을 막아 두었습니다(`noindex`). 전화번호·이메일·상세 주소·카드/주문 정보·직장(회사·사업장) 이름·거주 구 이름은 넣지 않습니다.
데이터를 바꾸려면 `data.json`만 고치고 `python3 build.py`를 다시 실행하면 됩니다.
